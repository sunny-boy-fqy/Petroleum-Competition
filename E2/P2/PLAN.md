# E2/P2 增强与吞吐标定

> 所属阶段：[E2](../PLAN.md)　|　总计划：[v4/PLAN.md](../../../PLAN.md)

> 本目录是最小可执行单元：`code/` 放本 P 专属脚本，`docs/` 放本 P 的说明与结论。

## 1. 目标

实现曲线随机掩码、深度抖动、段置换等增强，并用单折小规模实验标定吞吐（点/秒）与 batch 上限。

## 2. 为什么需要这一步

80 井太少，正则化与增强是防过拟合的主要手段；吞吐标定决定 E3 的预算可行性。

## 3. 代码

- `src/data/augment.py`
- `E2/code/throughput.py`

## 4. 产物

- `reports/E2_throughput.json`

## 5. 完成判据

- 给出每折耗时估计与显存/内存峰值；增强不改变标签语义

## 6. 禁止事项

- 增强破坏占位行的标签一致性

## 7. 执行提示

- 先跑最小可复算版本（单折 / 小样本），确认口径正确后再全量。
- 结果写入本 P 的 `docs/` 与 `v4/reports/E2_P2_*.json`。
- 预注册 Gate 后才允许看结果；预注册文件为 `v4/reports/E2_P2_gate_prereg.json`。
- 任何结论必须附「复算命令」与「产物 sha256」。
