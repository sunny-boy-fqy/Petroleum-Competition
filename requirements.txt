# ============================ 安装纪律（务必先读） ============================
# 基础栈由平台镜像**预装**，**不得 pip 替换**：
#     python==3.11 / torch==2.8.0 + torch_npu==2.8.0 / CANN 8.3rc2 / arm64（Ascend 910B）
# 因此本文件**不再声明 torch**（旧版写了 torch==2.4.0，`pip install -r` 会把
# 镜像里的 torch 换掉 —— 这是明确禁止的）。
#
# 【给用户的 pip 安装清单】只有下面「额外轻量包」里的 required 部分需要安装：
#     numpy
#     pandas
#     scipy
#     scikit-learn
#     einops
# 推荐（平台"迭代曲线"观测；缺失时自动降级为 JSONL，不阻塞）：
#     tensorboard
# 不需要（有文档化降级路径，装了也不会更快）：
#     pyarrow            # 分片缓存是 .npz（numpy），没有代码 import pyarrow
#     onnx / onnxruntime # CPU 推理主路径是 torch.load(map_location="cpu")
#
# 版本**不钉死**：torch 的 wheel 不依赖 numpy（2.7.1 的 Requires-Dist 里没有 numpy），
# 基础镜像通常自带、但不保证，所以 numpy 也由 pip 补装（已装时只会打印 already satisfied）；
# 其余包按 pip 解析出的兼容版本即可。
#
# 【两阶段版本策略】精确版本不靠这里猜，而靠**实机事实**：
#   ① bash v4/E0/code/setup_deps.sh               # 只给包名，让 pip 按当前镜像解析
#   ② 装完自动 pip freeze -> versions/locks/cloud_frozen.txt（进 git，供提交复现）
#   ③ bash v4/E0/code/setup_deps.sh --from-frozen  # 重建镜像/复现时按①的实测版本精确安装
#      （白名单挑包，构造上不可能碰 torch/torch_npu/nvidia-*/cuda-*/ascend/cann/triton）
#
# 安装脚本：v4/E0/code/setup_deps.sh（--no-cache-dir + 装完清缓存 + 拒绝触碰 torch）
# 训练侧清单：versions/locks/cloud.txt ；推理侧：versions/locks/submit.txt
# 说明文档：docs/image_requirements.md / docs/dependencies.md
